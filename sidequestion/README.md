# 곁질문(`/btw`)

일반 채팅이나 작업의 메인 에이전트·작업자 대화에서 `/btw 질문`을 입력하면, 본 작업을 방해하지 않고 현재 상황을 물어볼 수 있습니다. `/btw` 또는 **곁질문** 버튼으로 기록을 열고, 추가 질문·중지·비우기를 사용할 수 있습니다.

곁질문은 마지막으로 저장된 에이전트 컨텍스트를 읽어 답합니다. **도구 실행, 파일 수정, 메인 작업 지시는 수행하지 않습니다.** 모델이 도구 호출을 반환하더라도 실행하지 않습니다. 작업 실행은 메인 대화에서 요청해야 합니다.

## 실행과 문맥

- 본 작업이 실제 사용한 OpenAI 프로필과 모델을 사용합니다. 프로필이 삭제되거나 연결·모델 설정이 달라지면 본 작업을 한 번 실행해 스냅샷을 갱신해야 합니다.
- 도구 호출·결과의 짝과 OpenAI 응답 상태를 포함한 구조화 스냅샷을 복사합니다. 준비 과정의 요약은 메인 대화 기록을 바꾸지 않습니다.
- 최근 성공한 문답을 최대 20묶음까지 입력 예산 안에서 유지하고, 오래된 문답과 큰 컨텍스트는 곁질문 전용 요약으로 줄입니다. 추론 상태 같은 내부 데이터는 요약용 텍스트로 풀어 넣지 않습니다.
- 질문은 최대 4000자, 실행은 상위 세션마다 1개·서비스 전체 4개이며, 요약을 포함해 요청당 120초로 제한됩니다.
- 창 크기에서 출력 예약량과 안전 여유를 제외해 입력 예산을 계산합니다. 출력 예약 기본값은 8192이며 `ARTEX_BTW_MAX_OUTPUT_TOKENS`로 256–32768 범위를 지정할 수 있습니다. **ChatGPT 구독 연결은 서버가 출력 길이를 관리**하므로 이 값이 실제 출력의 강제 상한이 되지는 않습니다.

패널을 닫거나 새로 고쳐도 진행 중인 요청은 계속됩니다. **중지**는 곁질문만 취소하며, **비우기**는 곁질문 실행과 기록을 지우되 본 작업과 스냅샷은 유지합니다. 서버 재시작으로 끊긴 응답은 중단 상태와 이미 받은 텍스트를 보존하며 자동 재실행하지 않습니다.

## 저장과 인터페이스

스냅샷은 `side_question_sessions`, 질문·응답·사용량은 `side_question_requests`에 저장합니다. 작업 아카이브에도 포함됩니다. 화면 로그를 이어 붙여 컨텍스트를 복구하지는 않습니다.

`{parent}`는 `/api/conversations/{id}`, `/api/tasks/{id}/chat`, `/api/tasks/{id}/intents/{iid}` 중 하나입니다.

| 요청 | 동작 |
|---|---|
| `GET {parent}/side-questions?before={ordinal}` | 문답·진행 상태·스냅샷 정보·다음 커서 조회 |
| `POST {parent}/side-questions` | `question`, `client_request_id`로 질문 제출 |
| `DELETE {parent}/side-questions` | 취소 후 기록 비우기 |
| `GET /api/side-questions/{requestID}/events` | 누적 응답 SSE 구독 |
| `POST /api/side-questions/{requestID}/cancel` | 해당 질문 중지 |

관련 구현: [스냅샷](capture.go), [입력 예산](request.go), [요약](context.go), [응답](service.go), [HTTP·저장 조율](../server/side_questions.go). 검증은 현재 코드의 테스트를 기준으로 하며, 원본 저장소의 과거 모델 평가 기록은 포함하지 않습니다.
