# 연결·기능 차이

[변경점 전체 목록](../changes.md) · 비교 기준: ARTEX/global `fdfb7a1`

원본의 다중 에이전트·도구·MCP·Skills·트래픽 증거·보고서 기능을 유지합니다. 이 포크의 주요 추가 기능은 ChatGPT 구독 연결, 관리 브라우저와 이미지 전달, 설정·조회 화면의 확장입니다.

## 모델과 계정

| 원본 | 현재 |
| --- | --- |
| 여러 공급자의 API 연결 | OpenAI Responses 전용. API 키와 ChatGPT 구독을 선택 |
| API 키 중심 인증 | ChatGPT 로그인·갱신·연결 해제와 한도 재확인 |
| 모델 ID 조회·입력 | 선택한 인증의 모델 목록, 계정이 제공하는 프로그램·추론 옵션 표시 |
| 연결 확인 결과 | 실제 응답 모델·프로그램·시각을 저장하고 입력 변경과 이전 결과를 구분 |

ChatGPT 계정 연결은 ARTEX 관리자 로그인과 별개입니다. 구독 한도를 API 키로 자동 우회하지 않습니다. 요청 옵션과 계정별 조회 정보의 차이는 [OpenAI 처리](openai.md)에 설명합니다.

## 브라우저와 이미지

원본에도 브라우저 MCP가 있었습니다. 현재는 Docker의 MCP·Playwright·Chromium 버전과 실행 경로를 맞추고, 새 설치에서 기본 `browser`를 활성화합니다. 기존 사용자가 비활성화하거나 수정한 설정은 유지합니다.

- JavaScript 페이지·네트워크·DOM을 실제 Chromium에서 확인합니다.
- 로그인·추가 인증이 필요하면 사용자가 같은 브라우저 화면을 조작하고 에이전트에게 제어를 반환할 수 있습니다.
- 쿠키·localStorage·sessionStorage를 같은 세션의 재개에 사용합니다. 다른 의도·대화의 인증 상태를 자동으로 공유하지 않습니다.
- MCP 스크린샷과 `Read` 이미지가 모델의 시각 입력으로 전달되며, 파일·해시를 보존해 재개에 사용합니다.

브라우저 사용 여부는 도구 설정과 모델 판단을 따릅니다. 브라우저 검증을 별도 필수 단계로 만들거나 응답을 자동으로 사실·자산 그래프에 등록하는 단계를 추가하지 않습니다. 사용법과 한도는 [브라우저·설정](../browser-and-presets.md)을 참고하세요.

## 작업·자원 설정

원본의 작업 템플릿 저장·적용 기능에 작업 이름, 시간 제한, 계획 주기, 초기 의도 생성, 커버리지 설정을 추가했습니다. 실습 전체·운영 관찰·운영 일반·운영 확장의 기본 템플릿 4종은 설명 6줄과 목표 1문장으로 제공하며, 등록 이력이 없는 환경에 한 번만 추가합니다. 템플릿을 적용한 뒤 편집한 최종값으로 작업을 생성하며, 모델·연결 작업·회사 선택은 바꾸지 않습니다. [기본값과 사용자 설정 보존](../browser-and-presets.md#작업-템플릿)

시스템 설정에서 작업당 Worker 수와 브라우저 동시 실행 한도를 조정하고, 작업 목록의 **동시 실행 설정**에서 전체 작업의 동시 실행 한도를 조정합니다. Worker 수는 작업 생성 시 저장하여 이후 전역 설정 변경으로 기존 작업을 바꾸지 않습니다.

## 실행 상태와 조회

탐색 그래프에 최신 페이지·전체 건수·이전 기록 커서를 제공하고 연결된 이웃 노드를 함께 표시합니다. 작업 화면은 실행 중 Worker의 단계·도구·최근 신호와 현재 모델·자원 설정을 보여 줍니다. 이 상태 표시는 탐색 방향이나 완료 판정을 추가로 제어하지 않습니다.

실행 기록에는 요청 설정과 실제 응답 메타데이터를 구분해 남깁니다. 원문 녹화가 꺼져 있어도 모델·인증 방식·지침/도구 정의의 해시 등 비교 정보를 기록하며, 자격증명과 원문 프롬프트를 그 메타데이터에 복사하지 않습니다. [동작·표시](behavior.md), [오류·상태 보존](fixes.md)을 함께 참고하세요.
