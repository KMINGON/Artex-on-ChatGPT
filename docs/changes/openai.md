# OpenAI 처리

[변경점 전체 목록](../changes.md) · 비교 기준: ARTEX/global `fdfb7a1`

원본의 여러 공급자 연결을 OpenAI Responses로 통합하고 ChatGPT 구독 인증을 추가했습니다. API 키와 구독은 같은 응답 어댑터를 사용하지만 모델 목록·요청 옵션·계정 상태는 구분합니다. 아래 내용은 현재 ARTEX 코드의 동작이며 특정 계정의 권한이나 서비스 정책을 보장하지 않습니다.

## 응답 상태와 완료 판정

| 원본 대비 변경 | 현재 동작 |
| --- | --- |
| 응답 상태 보존 | 완료 응답의 reasoning 원형·`phase`·항목 순서를 도구 왕복과 저장·재개에서 유지 |
| 내용 변경 | 편집·압축으로 내용이 달라지면 해당 메시지의 원형 공급자 상태 제거 |
| 스트림 완료 | HTTP 200이나 `[DONE]`만으로 성공 처리하지 않고 완료·실패·미완료 이벤트 확인 |
| 도구 입력 | 불완전한 JSON·출력 제한으로 잘린 호출은 실행하지 않음 |
| 사용량 | 실패한 응답에도 실제 수신한 사용량을 반영하고, 미수신과 0을 구분 |
| 오류 정보 | 오류 코드·요청 ID·처리 단계·요청 크기를 기록. 원문 인증·추론 데이터는 진단 로그에 복사하지 않음 |

원본에도 일반 대화 압축이 있었습니다. 현재 차이는 OpenAI 상태가 도구 왕복과 저장 경계에서 유실되지 않도록 하는 처리이며, 별도의 탐색 단계가 아닙니다. [`chatgptllm/state.go`](../../chatgptllm/state.go), [`chatgptllm/stream.go`](../../chatgptllm/stream.go)

## API와 구독의 요청 차이

| 항목 | API 키 | ChatGPT 구독 |
| --- | --- | --- |
| 인증 | 저장·입력한 OpenAI API 키 | 연결한 ChatGPT 계정의 갱신 가능한 토큰 |
| 모델 목록 | 해당 키로 조회. 없는 기능 정보는 코드의 호환성 정보를 참고 | 선택한 계정의 모델·지원 프로그램·추론 옵션 조회 |
| `max_output_tokens` | 설정한 출력 상한 전송 | 전송하지 않음 |
| `temperature` | 지원 조건에 맞는 내부 요청에서 전달 | 전송하지 않음 |
| 추론 강도 | 선택한 값 또는 기본값 생략 | 계정 카탈로그의 선택지 사용. 기본값 선택은 필드 생략 |
| 프로그램 | 생략 또는 `standard`·`daybreak_blue`·`daybreak_red` | 생략 또는 명시적 `standard` |
| 도구·이미지 | 로컬 function·MCP와 이미지 결과 | 같은 변환·실행 경로 |

구독의 보조 호출에는 요청 형태에 따라 간결한 출력 안내와 로컬 시간·수신량 한도를 적용합니다. 이는 서버 생성 토큰의 강제 상한이 아닙니다. 일반 작업의 모델을 다른 모델이나 API 키 방식으로 바꾸어 성공 처리하지 않습니다. [`chatgptllm/request.go`](../../chatgptllm/request.go), [`chatgptllm/budget.go`](../../chatgptllm/budget.go)

## Daybreak 선택

모델 목록의 **지원 정보**, 프로필의 **요청 값**, 완료 응답의 **실제 값**을 따로 표시합니다. 모델 이름만으로 계정의 프로그램 권한을 추정하지 않습니다.

- API의 새 설정은 프로그램 필드를 생략합니다. 고급 설정에서 직접 선택한 값은 그대로 전송하며 모델 변경만으로 조용히 바꾸지 않습니다.
- 구독 모델에 `daybreak_blue`가 제공되면 목록에 Daybreak로 표시하고 새 설정은 프로그램 필드를 생략합니다. `standard`만 제공되면 Standard를 명시합니다. 정보가 없으면 미확인으로 표시합니다.
- 기존에 Standard를 명시한 구독 설정은 유지합니다. 자동 선택으로 바꾸는 경우 사용자가 전환하고 다시 연결을 확인합니다.
- 연결 확인과 저장된 프로필 카드는 실제 완료 응답의 모델·프로그램을 표시합니다. `access_programs: null`은 Standard, 필드 누락·빈 객체는 미확인으로 처리합니다.
- 현재 구독 설정에서는 Blue·Red를 명시하는 값을 받지 않습니다. API는 프로그램 값의 형식을 확인하고 실제 모델·계정의 지원 여부는 서버 응답으로 확인합니다.

**Daybreak 확인**과 **연결 확인**은 현재 설정으로 연결을 검사합니다. 자동으로 다른 프로그램을 강제하거나 여러 모델을 순회하는 시험이 아닙니다. 코드에 포함된 모델 호환성 정보도 계정의 실제 접근 권한을 대신하지 않습니다. [`chatgptllm/capabilities.go`](../../chatgptllm/capabilities.go), [`chatgptllm/catalog.go`](../../chatgptllm/catalog.go), [`chatgptllm/metadata.go`](../../chatgptllm/metadata.go)

## 연결 변경과 오류 복구

첫 사용 가능한 프로필의 기본 지정, 대화에서 만든 작업의 모델 상속, 프로필 적용·캐시 무효화를 함께 처리합니다. 연결이 없는 작업은 설정을 기다리며, 프로필 적용 확인이 실패했을 때 이전 연결로 새 요청을 조용히 실행하지 않습니다.

계정·키·모델·명시 프로그램이 달라지면 이전 연결의 원형 추론 상태를 새 연결로 재전송하지 않습니다. 작업 파일·과거 기록은 보존하되 새 컨텍스트를 사용합니다. 구독 한도 차단은 연결 단위로 보관하며 토큰 갱신이나 서버 재시작만으로 해제하지 않습니다. **한도 재확인**은 실제 모델 요청으로 성공을 확인하는 기능입니다.

출력을 전달하기 전의 알려진 일시 오류와 로컬 스트림 중단만 설정된 재시도 범위에서 같은 연결·요청으로 다시 시도합니다. 양의 초 단위 `Retry-After`와 취소를 따릅니다. 출력이 시작된 요청·실행한 도구·인증 실패·한도 오류·알 수 없는 오류를 전체 재생으로 복구하지 않습니다. 완료 이벤트 없는 `[DONE]`, 잘못된 이벤트, 크기 초과는 로컬 연결 중단과 구분합니다.

헤더·본문에 15분 동안 바이트가 없으면 대기를 취소합니다. keepalive가 도착하는 정상 장기 응답은 무신호로 취급하지 않습니다. [`chatgptllm/errors.go`](../../chatgptllm/errors.go), [`chatgptllm/provider.go`](../../chatgptllm/provider.go), [`chatgptllm/stream_idle.go`](../../chatgptllm/stream_idle.go)

## 실행별 요청·응답 기록

`llm_usage.metadata`에는 요청 모델·인증 방식·추론·프로그램·빌드 정보, 시스템 지침·도구 정의의 해시와 실제 응답 메타데이터를 구분해 저장합니다. 원문 녹화 설정과 별개이며 원문 프롬프트·도구 인자·자격증명은 이 비교 메타데이터에 포함하지 않습니다.

`max_output_tokens_requested`는 호출자가 요청한 값으로, 구독에서 서버에 전송했다는 뜻은 아닙니다. 과거 행에 없는 정보를 사후 추정하지 않습니다. [실행 기록 구현](../../llmrec/llmrec.go), [화면 표시](behavior.md#작업-상태와-그래프-표시)
