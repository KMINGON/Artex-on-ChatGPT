# 원본 대비 변경점

비교 기준은 [artex-global `fdfb7a1`](https://github.com/jiwoochris/artex-global/commit/fdfb7a17b7da5e2de716c0e98475ec77a41c64c6)입니다. 해당 원본과 **현재 코드의 차이**를 설명합니다. 설치는 [README](../README.md#빠른-시작)를 참고하세요.

작업의 기본 흐름은 원본과 같습니다. Goals가 목표를 나누고, Planner가 탐색 방향을 배정하며, 여러 Worker가 도구를 실행해 자산·사실·발견을 기록합니다. Planner는 결과를 읽어 다음 방향과 목표 달성을 판단합니다. 원본의 의도 분할·우선순위·재검증 방식을 유지하면서, 한국어 지침의 자산 등록·관찰과 추론 구분·ID 설명을 실제 도구 계약에 맞춥니다.

공통 에이전트 지침에는 추가적인 완료 검토, 미완료 질문 대장, 별도 검증 단계를 요구하지 않습니다. `실습 · 전체 검증` 템플릿은 작업 입력으로 완료 전 누락·미탐색 영역을 다시 확인하고, 추가 탐색 결과와 실행 예산에 따라 종료 사유와 목표 달성 여부를 구분하도록 안내합니다. 원본과 달리 보존하는 부분은 OpenAI 연결, 실행 오류 수정, 저장·재개 중 정보 손실 방지, 브라우저 실행 환경과 설정입니다. [작업 템플릿](browser-and-presets.md#작업-템플릿)

원본에도 브라우저 MCP, 트래픽 증거 연결, 자동 보고서, 가로채기, 대화 압축과 탐색 그래프 요약이 있었습니다. 이 기능 자체를 포크의 신규 기능으로 설명하지 않습니다. [브라우저·설정](browser-and-presets.md), [트래픽 증거](finding-traffic-evidence.md)에서 현재 사용 조건을 확인할 수 있습니다.

실행 안정성 보완이 발견 수나 진단 속도의 향상을 보장하지는 않습니다. 모델·추론 강도·작업 입력·활성 도구·대상 상태를 맞춘 비교가 별도로 필요합니다.
